
ASSET MANAGEMENT SYSTEM - BRD (SINGLE COMPANY DEPLOYMENT)
=========================================================

PROJECT OVERVIEW
----------------
Build an enterprise Asset Management System for a single organization.
The solution will be hosted on shared hosting using Laravel, MySQL,
Blade, Alpine.js, Tailwind CSS and PWA support.

MULTI-TENANCY
-------------
Not Required.
This is a single-company deployment.

OBJECTIVES
----------
1. Centralized asset repository.
2. Complete asset lifecycle tracking.
3. Asset assignment and movement tracking.
4. QR/Barcode enabled operations.
5. Audit readiness and traceability.
6. Maintenance tracking.
7. Disposal and scrap management.
8. Reporting and dashboards.
